# LTspice-Buck-Converter-Analysis
This project models a 12V-to-5.7V DC-DC Buck Converter in LTspice. Driving a Si7336ADP MOSFET and 1N5819 Diode at 2.5kHz (35% Duty Cycle), the simulation captures realistic Discontinuous Conduction Mode (DCM) dynamics and phase node parasitic ringing for hardware production.
